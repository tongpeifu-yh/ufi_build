## 提取固件

固件在两个提取出的分区中存在，一个是NON-HLOS.bin，另一个是system.img的`/etc/firmware`目录下。前者是fat raw格式镜像，挂载后把image文件夹下的文件提取出来即可。后者是ext4分区镜像，并且部分文件是软链接，需要到真正目录下找到。

固件文件统一放在rootfs的/lib/firmware目录下。

`NON-HLOS.bin`中的固件放置方式如下：

| 文件/文件夹                                                                                                                                              | 建议存放路径                                          | 说明                                                                                                       |
| -------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| **`modem.*`** 文件                                                                                                                               | `/lib/firmware/`                                    | **基带核心固件** ，负责4G通信，直接放固件根目录。                                                    |
| **`wcnss.*`** 文件                                                                                                                               | `/lib/firmware/qcom/msm8916/`或者`/lib/firmware/` | **WiFi/蓝牙固件** ，现代内核通常指定此设备专属路径，但也可直接放在固件根目录。                       |
| **`cmnlib.b*`** 、 **`playread.b*`** 、 **`widevine.b*`** 、 **`isdbtmm.b*`** 、**`keymaste.b*`** 及对应`.mdt` | `/lib/firmware/`                                    | **安全/DRM/广播相关固件** 。部分发行版会放入`postmarketos`子目录，直接放固件根目录通常也能被识别。 |
| **`modem_pr`** 整个文件夹                                                                                                                        | `/lib/firmware/`                                    | **运营商配置文件** ，需整体复制，保持原有目录结构。                                                  |

`system.img`中的固件方式方式如下：

| 文件 / 文件夹                 | 建议存放路径                                | 说明                                                                                                                          |
| ----------------------------- | ------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| **`*.fw`** 文件       | **`/lib/firmware/qcom/`**           | **GPU 固件** ，直接放入`qcom/`目录，无子目录。                                                                        |
| **`venus.*`** 文件    | **`/lib/firmware/qcom/venus-1.8/`** | **Venus 视频固件** 。Linux 内核使用此子目录路径，并加载`venus.mbn`。                                                  |
| **`wlan`** 整个文件夹 | **`/lib/firmware/`**                | **WiFi/蓝牙配置文件** 。这是新增的关键部分， **整个`wlan`文件夹需要按原有结构复制到`/lib/firmware/`目录下**。 |

system.img中的固件中，wlan/prima文件夹下有三个文件，其中WCNSS_qcom_cfg.ini、WCNSS_qcom_wlan_nv.bin这两个是软链接。一种方法是把安卓root后直接复制出来，另一种是找对应分区，比如WCNSS_qcom_wlan_nv.bin在persist分区（/persist/WCNSS_qcom_wlan_nv.bin），可以用7zip打开Qualcomm Premium Tool提取出的persist.mbn，在其中找到相应的文件；WCNSS_qcom_cfg.ini在data分区（/data/misc/wifi/WCNSS_qcom_cfg.ini），可以7zip打开Qualcomm Premium Tool提取出的userdata.img，在`/misc/wifi`下找到该文件。
